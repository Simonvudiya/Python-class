Conditions

1. What is a conditional statement?

A conditional statement allows a program to make a decision. In everyday life, we make decisions such as: "If it is raining, carry an umbrella." In Python, that same decision looks like this:

if it_is_raining:
    carry_umbrella()

The basic idea is always the same shape:

IF something is TRUE
    DO something
ELSE
    DO something else

A condition normally produces one of two results: True or False. For example:

age = 20

age >= 18
Result
True
Conditions

2. Basic if syntax

The general structure is:

if condition:
    statement
    statement
    statement

For example:

age = 20

if age >= 18:
    print("Customer is an adult")
Teaching point

Notice the colon at the end of if age >= 18:, and notice the indentation on print("Customer is an adult"). The indented code belongs to the if statement — Python uses indentation, not brackets, to know what's "inside" a block.

Students often confuse = with ==. age = 20 is assignment — it stores a value. age == 20 is comparison — it asks a true/false question.

4. Practical example: adult or minor

Let's determine whether a customer is an adult or a minor:

customerAge = 20
adultAge = 18

if customerAge >= adultAge:
    print("Customer is an adult")
else:
    print("This customer is a minor")
Output
Customer is an adult

Calculating the age difference

We can make the program more informative:

customerAge = 20
adultAge = 18

if customerAge >= adultAge:
    ageOverMin = customerAge - adultAge
    print("Customer is an adult")
    print(f"The customer is {ageOverMin} years over the minimum age.")
else:
    ageUnderMin = adultAge - customerAge
    print("This customer is a minor")
    print(f"The customer is {ageUnderMin} years under the minimum age.")
Output — for a 20-year-old
Customer is an adult
The customer is 2 years over the minimum age.
Output — for a 15-year-old
This customer is a minor
The customer is 3 years under the minimum age.

5. Multiple conditions with elif

Sometimes we have more than two possibilities. For example, suppose we want to determine a student's educational level based on age:

AgeCategory
Below 2Daycare
2–4Kindergarten
5–9Elementary School
10–15High School
16+College
 
candidateAge = 13

if candidateAge >= 16:
    print("Candidate belongs to College")
elif candidateAge >= 10:
    print("Candidate belongs to High School")
elif candidateAge >= 5:
    print("Candidate belongs to Elementary School")
elif candidateAge >= 2:
    print("Candidate belongs to Kindergarten")
else:
    print("Candidate belongs to Daycare")
Output
Candidate belongs to High School
Why check from the highest age first?

Python evaluates conditions from top to bottom. If candidateAge >= 16 is checked first and the student is 20, Python executes that block and stops checking the remaining elif statements.

Functions

6. Converting the logic into a function

We may want to use this calculation many times. Instead of repeatedly writing the same if chain, we can wrap it in a function:

def schoolCat(name, age):

    if age >= 16:
        print(f"{name} belongs to College")

    elif age >= 10:
        print(f"{name} belongs to High School")

    elif age >= 5:
        print(f"{name} belongs to Elementary School")

    elif age >= 2:
        print(f"{name} belongs to Kindergarten")

    else:
        print(f"{name} belongs to Daycare")

Now we can call the function as many times as we like:

schoolCat("Jigiri", 1)
Output
Jigiri belongs to Daycare
schoolCat("Mary", 17)
Output
Mary belongs to College
Teaching point

A function allows us to write code once and reuse it many times.

Loops

7. for loops

Imagine we have five students:

studList = ["Frank", "Claret", "Iniobong", "Silas", "Joseph"]

If we want to print every name, we could write five separate print() calls — but that becomes impractical once we have 1,000 students. A for loop solves this:

for name in studList:
    print(name)
Output
Frank
Claret
Iniobong
Silas
Joseph

How a for loop works

The general syntax is:

for item in container:
    do_something()

Python takes one item at a time — name is a temporary variable that holds whichever item is currently being processed: Frank → Claret → Iniobong → Silas → Joseph.

Loops

8. Looping through numbers

We can also loop through a list of ages:

studAgeList = [2, 5, 8, 15, 23]

for age in studAgeList:
    print(age)

5

Loops

9. Combining functions and loops with zip()

Now we have two related lists:

studList = ["Frank", "Claret", "Iniobong", "Silas", "Joseph"]
studAgeList = [2, 5, 8, 15, 23]

We want to process each student's name together with their age. zip() combines corresponding items from two lists:

for student, studentAge in zip(studList, studAgeList):
    schoolCat(student, studentAge)
Output
Frank belongs to Daycare
Claret belongs to Kindergarten
Iniobong belongs to Elementary School
Silas belongs to High School
Joseph belongs to College
What does zip() do?

It pairs up items by position: Frank→2, Claret→5, Iniobong→8, Silas→15, Joseph→23. zip(studList, studAgeList) lets us walk through two lists together, in lockstep.

Loops

10. while loops

A while loop repeats code while a condition remains true. Basic syntax:

while condition:
    statement

Example:

counter = 0

while counter < 5:
    print(counter)
    counter += 1
Output
0
1
2
3
4

Understanding counter += 1

counter += 1 is shorthand for counter = counter + 1. So the value walks: 0 → 1 → 2 → 3 → 4, and eventually counter < 5 becomes false and the loop stops.

Loops

11. Infinite loops

This is a very important concept for beginners. Consider:

counter = 0

while counter < 5:
    print(counter)

What is missing? We never increase counter. So counter stays 0 forever, the condition counter < 5 is always True, and this creates an infinite loop.

The correct version restores the increment:

counter = 0

while counter < 5:
    print(counter)
    counter += 1
Teacher warning

Every while loop should have a clear mechanism that eventually makes its condition false — unless an intentional infinite loop is being created on purpose.

Loops

12. Using while with our student example

We can process our students using a while loop instead of a for loop:

studList = ["Frank", "Claret", "Iniobong", "Silas", "Joseph"]
studAgeList = [2, 5, 8, 15, 23]

stdListLen = len(studList)
counter = 0

while counter < stdListLen:

    schoolCat(
        studList[counter],
        studAgeList[counter]
    )

    counter += 1

The important part is studList[counter] and studAgeList[counter]. When counter = 0, Python fetches studList[0] and studAgeList[0] — which gives Frank, 2. Then counter += 1 moves on to the next student.

Functions

13. Returning results from functions

So far our function only uses print(). But functions can also return information:

def schoolEval(name, age):

    if age >= 16:
        return [name, "College"]

    elif age >= 10:
        return [name, "High School"]

    elif age >= 5:
        return [name, "Elementary School"]

    elif age >= 2:
        return [name, "Kindergarten"]

    else:
        return [name, "Daycare"]
result = schoolEval("Vincent", 13)
print(result)
Output
['Vincent', 'High School']

We can also unpack the result into two separate variables:

stdName, school = schoolEval("Vincent", 13)

print(stdName)
print(school)
Output
Vincent
High School

print() versus return

FunctionWhat it does
print()Displays something on the screen — nothing is handed back to the code.
returnSends a value back to the code that called the function, so it can be stored or reused.
 
def add(a, b):
    return a + b

answer = add(10, 20)
print(answer)
Output
30
Key idea

print() displays a result. return gives a result back to the program so it can be used again.

Functions

14. Documenting functions

Professional Python programmers document their functions using a docstring — a triple-quoted string right under the def line:

def schoolEval(name, age):
    """
    Determine the educational level of a student.

    Parameters
    ----------
    name : str
        Name of the student.

    age : int
        Age of the student.

    Returns
    -------
    list
        A list containing the student's name and
        educational level.
    """

    if age >= 16:
        return [name, "College"]

    elif age >= 10:
        return [name, "High School"]

    elif age >= 5:
        return [name, "Elementary School"]

    elif age >= 2:
        return [name, "Kindergarten"]

    else:
        return [name, "Daycare"]

We can ask Python for this documentation directly:

help(schoolEval)

We can also inspect the attributes available on the function:

dir(schoolEval)
Modules

15. Python modules

A module is a Python file containing reusable Python code. For example, we can create a file called demoscript.py:

def schoolEval(name, age):
    """
    Determine the educational level of a student.
    """

    if age >= 16:
        return [name, "College"]

    elif age >= 10:
        return [name, "High School"]

    elif age >= 5:
        return [name, "Elementary School"]

    elif age >= 2:
        return [name, "Kindergarten"]

    else:
        return [name, "Daycare"]

We can then import it into another Python program:

import demoscript

Or give it a shorter name:

import demoscript as ds

result = ds.schoolEval("Vincent", 13)
print(result)
Output
['Vincent', 'High School']
Modules

16. Module vs. package

For beginners, explain it this way:

TermWhat it isExample
ModuleUsually a single Python file.demoscript.py
PackageA structured collection of modules, usually organized in a directory. school_system/ 
school_system/
    __init__.py
    students.py
    teachers.py
    reports.py
Common misconception to avoid

Don't tell students "a module becomes a package when distributed globally." That's not technically correct. A package is an organizational structure containing modules — distribution is a completely separate concept.

Modules

17. Creating the module in Google Colab

Since you are using Google Colab, the easiest way to create the module file is with the %%writefile magic command:

%%writefile demoscript.py

def schoolEval(name, age):
    """
    Determine the educational level of a student.

    Parameters
    ----------
    name : str
        Student name.

    age : int
        Student age.

    Returns
    -------
    list
        Student name and educational level.
    """

    if age >= 16:
        return [name, "College"]

    elif age >= 10:
        return [name, "High School"]

    elif age >= 5:
        return [name, "Elementary School"]

    elif age >= 2:
        return [name, "Kindergarten"]

    else:
        return [name, "Daycare"]

Colab should report that it wrote demoscript.py. Then:

import demoscript as ds

result = ds.schoolEval("Vincent", 13)
print(result)
Output
['Vincent', 'High School']
Very important

The file extension must be .py, not .pyl. And if the file is demoscript.py, the import must be import demoscript — not import demoScript. Python module names are case-sensitive.
